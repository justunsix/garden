| Name                                        | Shortcuts            |
|---------------------------------------------|----------------------|
| Edit, Cut current line into cutbuffer       | Ctrl + k             |
| Edit, Paste contents of cutbuffer           | Ctrl + u             |
| Edit, redi last action                      | Alt + e              |
| Edit, undo last action                      | Alt + u              |
| Exit                                        | Ctrl + x             |
| File, Save                                  | Ctrl + s             |
| File, Save as, write to file                | Ctrl + o             |
| Search, forward or backware                 | Ctrl + f or Ctrl + b |
| Search, next occurrence forward or backward | Alt + f or Alt + b   |
