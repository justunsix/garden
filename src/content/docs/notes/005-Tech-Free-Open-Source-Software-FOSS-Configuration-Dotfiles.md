  Software (FOSS)

Collection of Dotfiles for configuration of different FOSS software.

The dotfiles are mostly licensed under MIT or GPL.

- [mylinuxforwork/dotfiles](https://github.com/mylinuxforwork/dotfiles?tab=readme-ov-file) -
  Hyprland, Linux
- <https://github.com/Arkham/dotfiles.nix>
- [DoTheEvo Ansible automation with
  dotfiles](https://github.com/DoTheEvo/ansible-arch) - Ansible,
  ArchLinux
- [Maria Solano dotfiles](https://github.com/MariaSolOs/dotfiles) -
  Neovim, shell, terminal programs, Hyprland, Pi agent harness
- [Roy-Fokker dotfiles](https://github.com/Roy-Fokker/dot-files) -
  Emacs, Neovim, Windows Terminal
- [bashbunni/dotfiles](https://github.com/bashbunni/dotfiles) - Doom
  Emacs, NixOS, Sway, i3
- [David Wilson from System Crafters
  dotfiles](https://github.com/daviwil/dotfiles) - Emacs, GNU GUIX,
  Stow, qutebrowser, literate configuration files
- [Jeff Geerling Ansible
  playbook](https://github.com/geerlingguy/mac-dev-playbook) and
  [geerlingguy dotfiles](https://github.com/geerlingguy/dotfiles) -
  MacOS, Ansible
- [gtortone/dotfiles](https://github.com/gtortone/dotfiles) - ArchLinux,
  window manager, assembled desktop software with listing on software
  used and its function
- [Henrik Lissner dotfiles](https://github.com/hlissner/dotfiles) - Doom
  Emacs, NixOS, script organization, and other FOSS
- [Jess Frazell dotfiles](https://github.com/jessfraz/dotfiles) - NixOS,
  docker, scripts
- [JT's dotfiles](https://github.com/justunsix/dotfiles) - Dotfiles for
  cross platform Linux, Windows, MacOS, FreeBSD favouring terminal
  programs
- [Kaleo dotfiles](https://github.com/kaleocheng/nix-dots) - Nix for
  Nixos and other Linux distributions, home-manager
- [Linkarzu dotfiles](https://github.com/linkarzu/dotfiles-latest) -
  Neovim, MacOS, Tmux, Kitty, others with explanations
- [Matt Schwennesen dotfiles](https://github.com/mjschwenne/dotfiles) -
  NixOS, modern terminal programs, Emacs
- [kickstart.nvim](https://github.com/nvim-lua/kickstart.nvim) - Neovim
  starter configuration
- [phelipetls/dotfiles](https://github.com/phelipetls/dotfiles) -
  configuration files for Linux, macOS and WSL for use with Ansible
- [Steve Purcell Emacs](https://github.com/purcell/emacs.d) - Emacs
  configuration, multiple programming languages
- [Sacha Chua Emacs](https://github.com/sachac/.emacs.d/) - Emacs
  configuration with explanations
- [sioodmy/dotfiles](https://github.com/sioodmy/dotfiles) - NixOS and
  modules, dev shell, theme, home-manager
- [slyfox11186/script-repo](https://github.com/slyfox1186/script-repo/tree/main) -
  Cross platform scripts, AHK v1+v2 \| BASH \| BATCH \| JSON \| PERL \|
  POWERSHELL \| PYTHON \| WINDOWS REGISTRY \| XML
- [Victoria
  Drake](https://github.com/victoriadrake/dotfiles/tree/master) - Linux,
  install scripts, Pop<sub>OS</sub>! and Ubuntu
- [Derek Taylor aka DistroTube
  dotfiles](https://gitlab.com/dwt1/dotfiles) - window managers Qtile,
  Emacs, Neovim, others with explanations
