## Sequence to Building the Computer

- Read manuals of components and identify slots for items
- Register warranty for components
- Lay out motherboard on sheet it came in and its box
- Install CPU by opening and closing the latch
- Install RAM
- Install storage:
  - SSD remove or install heat sink if needed
  - Hard disks
- Install CPU cooler with paste, check how much with how to videos
- Case: Install fans, recommendation is 1-2 fans in front and 1 fan in
  back to push air from front of case to back
  - Fancy side of fan faces the front of the case
- Case: Install power supply
  - Check which cables required for use in power supply as cables are
    modular
    - Example:
      - PCI-E and motherboard cables
      - PCI-E for graphics
      - SATA Cables for storage
- Install motherboard into case
- Integrate motherboard with:
  - Case
  - Fans
  - Power
  - Audio
  - Other slots

## Running the Computer First Couple Times

- During boot up first time, wait a while as it accepts memory
- Use motherboard debug LEDs to diagnose basic issues like CPU/GPU, RAM
  not detected
- Check normal temperature for components and when they are under load
  and monitor their temperatures using software tool
- Download and install drivers and/or configure operating system
  settings
- Conduct stress testing and diagnostics of the machine
  - CPU, memory, I/O (stress-ng)
  - Memory: [Memtest86+](https://memtest.org/) - stand-alone memory
    tester for IA-32, x86-64, and LoongArch64 systems
  - GPU: gpu-burn, glmark2, Blender benchmark, 3DMark
  - CPU: Prime95 / [Mersenne Prime Search aka
    mprime](https://www.mersenne.org/download/#download),
    [y-cruncher](https://www.numberworld.org/y-cruncher/)
  - Monitoring: btop, amd-smi, NVIDIA control centre
