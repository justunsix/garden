| Name             | Shortcuts   |
|------------------|-------------|
| Command Palette  | C-S-p or F1 |
| Go to file       | C-p         |
| Go to symbol     | C-S-o       |
| Settings, open   | C-+         |
| Terminal, toggle | C-\`        |

C is Ctrl on Linux/Window and Command key on macOS

S is Shift

Some other shortcuts will follow the corresponding Zed mode like [Vim
mode](https://zed.dev/docs/vim) or [Helix
Mode](https://zed.dev/docs/helix).

## Commands

Call from command palette (Ctrl/Command + Shift + p or F1)

| Name                        | Shortcuts         |
|-----------------------------|-------------------|
| AI, new agent thread / chat | agent: new thread |
